Ce code vous sera demandé sur cet appareil à chaque ouverture de l'admin et après 10 minutes sans activité. Sans lui, la clé GitHub enregistrée reste illisible.

Comment obtenir ma clé ?
  1. Connecté à votre compte, ouvrez github.com/settings/tokens/new.
  2. Note : « Bâti-Pro admin ». Expiration : Custom, dans un an.
  3. Dans Select scopes, cochez uniquement public_repo (ou repo si le dépôt est privé).
  4. Cliquez Generate token, copiez la clé et collez-la ci-dessus.

Une clé par personne : chaque vendeur crée la sienne avec son propre compte GitHub, ajouté au dépôt dans Settings, puis Collaborators. Gardez votre clé secrète et supprimez-la sur GitHub en cas de perte.
